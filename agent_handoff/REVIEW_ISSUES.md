### 1. Diffusion control value mismatch

Priority: high

Command:

```bash
./venv_protenix/bin/python generate_control_values.py --verify --src solutions --chapters diffusion
```

Current failure:

```text
AssertionError: expressCoordinatesInFrame output mismatch
```

Relevant files:

- `solutions/diffusion/frames.py`
- `tutorials/diffusion/frames.py`
- `solutions/diffusion/control_values/diffusion_checks.py`
- `solutions/diffusion/control_values/_generate.py`
- `solutions/diffusion/control_values/express_coordinates_in_frame_out.pt`
- matching files under `tutorials/diffusion/control_values/`

Observed detail:

The deterministic `frame_atoms` test input is generated by a linear ramp:

```python
test_inputs["frame_atoms"] = _ramp((N_frame_geo, 3, 3), 5)
```

The middle frame is near-degenerate/collinear. In
`expressCoordinatesInFrame`, `w1 + w2` becomes close to zero, so
`F.normalize(w1 + w2, eps=1e-8)` can produce an arbitrary direction. The
saved control tensor expects the degenerate axis to collapse to zero for that
frame. Current implementation produces a max absolute mismatch around
`6.69e-2`.

Fix direction:

- Prefer replacing the geometry control input with a non-degenerate set of
  frame atoms, then regenerate the affected control value in both `solutions`
  and `tutorials`.
- Alternatively make `expressCoordinatesInFrame` explicitly handle degenerate
  `w1 + w2`, but only do that if it matches the intended AF3/Protenix behavior.
- After fixing, run:

```bash
./venv_protenix/bin/python generate_control_values.py --verify --src solutions --chapters diffusion
./venv_protenix/bin/python generate_control_values.py --verify --src tutorials --chapters diffusion
```

**Resolution (2026-06-22, fix agent)**: Replaced the ramp-generated
`frame_atoms` with a fixed-seed Gaussian + per-frame shift (`torch.Generator()
.manual_seed(0)`, shift `[1.0, 0.5, -0.5]`) in
`solutions/diffusion/control_values/diffusion_checks.py`. Regenerated
`express_coordinates_in_frame_out.pt` and propagated via `prepare_tutorials.py`.
Solutions verification now passes for all 6 chapters. Inline comment in
`diffusion_checks.py` documents the collinearity / BLAS-reproducibility
rationale so future authors don't reintroduce the ramp.

### 9. Direct Python imports are missing from the documented environment specs

Priority: medium

Status: resolved

Evidence:

```bash

for root in roots:
    files.extend(root.rglob("*.py"))

mods = {}
for p in files:
    tree = ast.parse(p.read_text())
    for n in ast.walk(tree):
        if isinstance(n, ast.Import):
            for a in n.names:
                mods.setdefault(a.name.split(".")[0], set()).add(str(p))
```
